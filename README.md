## 🚀 Featured Project

### [Knowvia — Enterprise AI Agent](https://github.com/Marghaleryrasooly/knowvia-agent)

An evidence-aware enterprise AI agent designed to provide employees with secure, reliable access to organizational knowledge.

**Highlights:**
- Retrieval-Augmented Generation (RAG) for grounded answers
- Evidence sufficiency evaluation and unsupported-answer handling
- Role-Based Access Control (RBAC)
- Multi-provider LLM integration
- Confirmation-gated agent actions and MCP integration
- Employee and administrator interfaces
- Automated testing and reliability evaluation

**Technologies:** Python, LLMs, RAG, Groq, Gemini, Ollama, SQLite, MCP
